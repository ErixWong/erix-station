## 六、操作坑（这轮新踩的，省下一个人的时间）

- **项目级 playwright 容器（:8935）的 MCP 版本参数名与默认实例不同**：点击/填表用 **`target`**（不是 `ref`）；`browser_console_messages` **必须给 `level`**；`browser_network_requests` **必须给 `static`**；`browser_take_screenshot` **必须给 `scale`**。默认实例（8931）不吃这些参数名，照旧记录写会一路报错。
- `POST /api/ports/:id/preview-ticket` 要求 **`Content-Type: application/json`**（文档写「无体（空 JSON `{}`）」）。上一轮文档里我给的 curl 片段少了这个头，照抄会 400——已在本文更正。
- `POST /api/sessions/:id/messages` 的字段是 **`content`**（不是 `text`）；`POST /api/admin/users` 的 `email` 必填。
- 预览票据 **60 秒**过期：在浏览器里排多步操作时，签完立刻用；跨 host 的 API 调用要**各 host 各有一票**（先访问后端 host 换 cookie）。
- `bash` 里 `UID` 是只读变量（上一轮踩过，这轮又差点踩）；`psql` 里 JSONB 取值要整体加括号。
