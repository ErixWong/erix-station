## 6. 真机探路的坑（省你两小时）

- **容器内发 HTTP 用 `node:http`，别用 `fetch`**：undici 会吞手工设的 `Host` 头 ⇒ Traefik 看到错的 host ⇒ 全部 404。探针脚本可复用：`/docker/erix_station_playwright/v017-accept2.cjs`、`p255.cjs`。
- **`#234` 同源门**：dev 是 `:8090`，`Host` 必须带端口（`station.fde.erix.vip:8090`），`Origin` 同值。漏端口 ⇒ 假 `cross_origin_forbidden`。
- `/api/sessions/:id/events` 是 **SSE**（会挂住）；读历史用 **`/events/history`**。
- `POST /api/sessions` 的 `cwd` 必须形如 `~/projects/<name>`；`POST /api/sessions/:id/messages` 字段是 **`content`**。
- 建用户：`email` 必填且合法、`git_host_id` 必须是存在的 UUID、`llm` 要 `{provider_id, main_model_id}`（取 LiteLLM 目录）。
- 预览票据 **60 秒过期**，跨 host 要各签一票（`POST /api/ports/:id/preview-ticket` **要求 `Content-Type: application/json`**）。
- **`docker manifest inspect` 会偶发失败**——权威核对走 `docker pull` + `docker image inspect .Id`（本单表格就是这么验的）。
- **Traefik edge 不会 reload 后来原子替换的 `routes.yml`**：整栈看着正常但预览/内部全 404 ⇒ `docker restart station-edge` 立刻通（§8.18）。
- 项目 playwright 容器 `erix_station_playwright`（:8935）的 MCP 参数名与默认实例不同：点击/填表用 **`target`**（不是 `ref`）、`browser_console_messages` 必给 `level`、`browser_network_requests` 必给 `static`、`browser_take_screenshot` 必给 `scale`（**只接受 `css` / `device`**）。
- GitHub 直连不稳时才挂代理：`git -c http.proxy=http://172.20.0.35:19001 …`（**`-c http.proxy=` 空值是「关代理」**）。判据打 `github.com`，不要打 `api.github.com`（两者可达性不同）。
