# 管理台截图资产（`docs/assets/admin-console/`）

这里放**证据截图**：issue / PR 里引用它们时必须用 **`main` 上的地址**，不要从功能分支或临时分支引用
（分支会被删、会被 force push，图就裂了——2026-11-28 实测踩过一次：把图寄存在 `assets-*` 分支上，
后来自己都意识到不可靠）。

## 规矩

- **只放打码图**：登录名、显示名、FDE、金额、最后活动时间一律模糊处理。
  仓库规矩是「证据只写形态不写值」，截图里的 dev 账号名与金额同属坐标，不进公开仓库。
- **命名**：`<issue 号>-<讲什么>.png`（例：`817-actions-icon-wide.png`）。
- **一张图一件事**：它是给某个判据做证据的，不是产品宣传图；别拿它当 UI 参考基线（UI 会变，图不会）。
- **别放截图做测试夹具**：e2e 截图仍落临时目录、不提交（口径见 `docs/testing.md` §1.2）。
